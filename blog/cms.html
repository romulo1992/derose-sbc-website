Campos essenciais: Título, Slug, Data, Categoria, Conteúdo. O conteúdo deve ser HTML simples (ex.: <p>...</p>).

Título
Dica: benefício claro + curto + sem enrolar.
Slug (id)
Apenas letras/números e hífen. (Sem acentos.)
Data (YYYY-MM-DD)
Use a data de publicação.
Categoria
Tempo de leitura (min)
Tags (separe por vírgula)
Tags alimentam busca e chips.
Excerpt
Imagem (path)
Para o post gerado em /posts, o template usa ../assets/... automaticamente.
Link (href)
Sugestão: ./posts/<slug>.html
Conteúdo do Post (HTML)
Dica: use apenas tags comuns: <p>, <h2>, <h3>, <ul>, <ol>, <li>, <blockquote>, <strong>, <em>, <a>.
Pronto.
Preview (post gerado)
O preview é do HTML gerado para /posts/<slug>.html (com paths relativos corretos).
